Este proyecto consistió en crear un sistema para administrar información de estudiantes conectando mi computadora con una base de datos en la nube. Primero, diseñé una tabla en Supabase organizada por matrículas para guardar nombres y carreras. Después, escribí código en Node.js que funciona como un puente para enviar nuevos registros y consultar los ya existentes automáticamente. Todo el proceso, desde la escritura del código hasta la configuración de la base de datos, fue respaldado y organizado en GitHub para demostrar un flujo de trabajo completo y funcional.
